## 1. ゲーム説明書

### 1.1 目的

プレイヤーは自分のカンパニーの「交易実務担当」です。タタルは商会長兼アドバイザーとして助言します。

グリダニアから開始し、都市内の「都市制覇対象」をすべて取得すると次の都市が解放されます。「任意の連合戦」は都市制覇数へ含まれません。次の順番で10都市すべてを制覇すると通常編の簡易エンディングとなり、高難度交易レイド「商戦 零式」が解放されます。零式全12層の先には「絶商戦」、さらに「酷商戦」と連勝記録戦「幻・商戦」が待っています。

1. グリダニア
2. リムサ・ロミンサ
3. ウルダハ
4. イシュガルド
5. クガネ
6. クリスタリウム
7. オールド・シャーレアン
8. ラザハン
9. トライヨラ
10. ソリューション・ナイン

キャラクター固有の長いストーリーやフィールド探索はありません。市場選択、買収戦、保有事業の管理がゲームの中心です。

#### 商戦木人討滅戦

市場から、実戦前の操作練習用となる`商戦木人 LEVEL 1～5`へ挑戦できます。都市制覇数に応じて段階解放され、解放済みLEVELは何度でも自由に再挑戦できます。参加費0、追加防衛なし、勝敗報酬なし、風なしです。木人側に押されても自社所有率1％で踏みとどまり、任意に終了するまで練習できます。訓練中も通常の毎秒収益とオフライン収益は止まりません。

木人内の出資・離反・勝敗は練習専用で、通常物件の所有権、商会資金、持越しLBゲージ、独立危険度、セーブデータへ一切反映されません。

#### 通常エンディング、商戦 零式、絶商戦、酷商戦、幻・商戦

- 通常編の10都市を全制覇すると、タタルと仲間が交易網完成を祝う簡易エンディングが流れ、ヘッダーに`商戦 零式`タブが追加されます。
- 零式は一般物件へ付ける強さラベルではなく、10都市の競合が地域ごとに連合した4層構成の、本作独自の高難度交易レイドです。
- 通常編で集めた保有事業・契約の支援元、装備スキル、SYNERGY、持越しLBゲージは利用できます。一方、通常編の地域・業界・交易網による敵予算弱体化と押込補正は無効です。
- 零式・絶・酷商戦は、敗北・撤退・報酬0の再戦では所有権・毎秒収益・通常物件の独立危険度を保護し、何度でも再挑戦できます。初回勝利では相場5%の攻略報酬を受け取り、利益独占（0%）・五分の祝儀（50%）・大盤振る舞い（100%）を選んで人脈の離反を清算します。仲介手数料と自社直接出資の確定損は発生します。この精算規則に、常に記録専用である幻・商戦は含みません。
- 各層の初回踏破で、その地域連合に属する通常事業の毎秒収益を10%強化します。対応する事業連携（SYNERGY）がある層では、その連携も1段階強化します。通常事業の所有権は変わりません。
- 価格帯は通常クリア後の毎秒収益を前提に6億～20億ギル、敵予算は同条件の通常戦比1.45倍、敵AIは専用LEVEL 5です。ランダムな即死ではなく、風・敵意図・資金チェックを学習して突破する設計です。
- 4層踏破後は、零式の第5層ではない単独の最終高難度交易戦「絶商戦」が解放されます。絶商戦は敵予算1.72倍、AI LEVEL 6で、ボス自体は通常物件として取得しません。初回勝利の人脈清算だけが通常進行へ残ります。
- 絶商戦踏破で真エンディングとなり、公式ファンキットの背景・ジョブアート12種・タタルを組み合わせた集合ビジュアルを表示します。踏破後は高難度タブから再表示できます。
- 絶商戦踏破後は、完成した戦術を崩されて組み直す超高難度戦「酷商戦」（サブタイトル`酷-もう1人のわたし`）が解放されます。
- 酷商戦踏破後は連勝記録戦「幻・商戦」が解放されます。一戦ごとに商戦 零式の全12層から相手をランダム抽選し、その層固有のギミックは変えず、競合の基礎資本と判断速度だけを絶相当へ引き上げます。
- 幻・商戦で永続保存する戦績は現在の連勝数だけです。勝利で1増え、敗北または戦闘中の撤退で0へ戻ります。戦前ブリーフィングを閉じただけでは連勝数も今回の相手も変わりません。最高記録、層別戦績、攻略報酬はありません。
- 幻・商戦は参加費0・攻略報酬0で、勝敗にかかわらず通常の商会資金、所有権、毎秒収益、人脈と独立危険度、持越しLBゲージ、通常進行を変化させません。戦闘内では専用に複製した資金・人脈・LBだけを使います。

用語整理は、現行型の8人レイドで1つの零式ティアが4つのコンテンツで構成され、所定の零式4層踏破が別カテゴリの絶レイドへの参加条件になる公式例を参考にしています。本作の地域連合、事業強化、絶商戦の内容はゲーム向けの独自アレンジです。

#### FFXIV用語による組織と段階解放

本作では、FFXIVのパーティ／アライアンス／カンパニー／ギルドの用語を、交易ゲーム向けに次のようにアレンジします。公式設定上の組織そのものと、本作独自の交易組織を混同しないよう、ゲーム独自の名称には「交易」「トレード」を付けます。

- **プレイヤー商会**: プレイヤーが運営する商会全体。FFXIV公式のフリーカンパニーやグランドカンパニーそのものではなく、本作独自の交易組織です。
- **トレード・パーティ**: 一回の買収戦へ参加する自社と保有事業・契約の支援元。個別の資金要求は、最初の事業・契約を取得した直後から利用できます。契約先そのものを所有・傘下化する意味ではありません。
- **交易ライトパーティ／LIMIT BREAK I**: 自社1枠＋支援元3件（合計4枠）で解放します。契約先を所有企業として数える意味ではなく、FFXIVの4人パーティを交易参加枠へ置き換えた本作独自の到達目標です。
- **交易フルパーティ／LIMIT BREAK II**: 自社＋支援元が合計8枠になった段階。より多くの事業・契約から支援を集める中盤の総力出資です。
- **競合企業連合（RIVAL ALLIANCE）**: 複数の商会・ギルド・カンパニーが共同戦線を組む、本作独自の高難度攻略組織です。序盤から表示せず、ウルダハ制覇後にタタルの説明とともに解放します。味方の協力協定・公的後援とは別枠です。
- **ギルド連携**: 木工、鍛冶、錬金、調理など、同じ専門分野の傘下を集めた事業シナジー。FFXIV公式のクラフター／ギャザラーと各ギルドの性格に対応させます。
- **グランドカンパニー**: FFXIV公式では都市国家が軍事・経済・技術を結集する統合司令部です。双蛇党、黒渦団、不滅隊は買収対象・所有物件・自社傘下にはならず、同時に1組織だけ許認可・調達・輸送の「公的後援」を申請できます。
- **公式名称と本作創作の区別**: 公式施設・職能組織そのものは原則として所有せず、周辺事業者、調達契約、交易協定として表現します。市場カードの`創作`、`公式名アレンジ`、`創作IF`バッジは本作独自設定を示します。複数世界を結ぶ「知識・技術交易連盟」も、`創作IF`バッジで区別する公式設定には存在しない終盤IF攻略線です。
- **ゴールドソーサー**: 攻略対象は公式施設本体ではなく周辺の興行契約です。MGPをギルへ換金する事業としては扱いません。

段階解放の対象は、保有事業・契約への個別支援要求や最初のLIMIT BREAKではなく、外部組織との提携や競合企業連合への攻略です。新しい組織機能が解放されるたび、タタルのアイコンと短い説明セリフを表示します。

#### SYNERGYとBURST TIME

本作では、事業グループの成立だけでなく、味方側の有利効果が働いて商会の力が高まった状態を広く`SYNERGY`と呼びます。

- 味方へ追い風が吹き、資金投入効果が上昇する
- トレード・パーティの参加枠が増え、一斉出資が強化される
- 同業種や同地域の企業がそろい、ギルド連携・地域連携が成立する
- 外部カンパニーとの協力協定やグランドカンパニーの公的後援が加わる

これらの条件が初めて成立したときは、タタルのアイコンとともに「SYNERGY発動！」を表示します。味方への追い風と、パーティ／ギルド／地域などの味方シナジーが同時に有効な時間は`BURST TIME`と呼びます。BURST TIME中は青を基調に金色を加えた専用演出で、通常の有利状態より強い好機であることを明確に伝えます。敵側だけに追い風が吹いている状態はBURST TIMEには含めず、赤い警告演出で区別します。

### 1.2 最初にすること

1. 起動演出の最後でカンパニー名を入力します。
2. 最初はグリダニアの交渉対象が表示されます。
3. 取得したい事業・契約を選びます。
4. 相場の3%にあたる仲介手数料を払って買収戦を開始します。
5. 「投資レベル」で金額を5段階から選び、「投資実行」でギルを積み、所有率を100%まで押し切ります。

デフォルトのカンパニー名は「タタルの大繁盛商店」です。カンパニー名、所持金、物件、装備スキル、戦闘連携1枠、外部協力／公的後援、解放説明の既読状態、零式・絶商戦・酷商戦の踏破、幻・商戦の現在連勝数、ED既読状態はブラウザの`localStorage`へ自動保存されます。幻・商戦の最高記録や層別戦績は保存しません。

### 1.3 基本ループ

1. 市場で物件・現在相場・都市進捗を見る
2. 買収戦で自社資金や支援資金を積む
3. 物件を取得して毎秒収益を増やす
4. 同業界・同地域・事業グループのボーナスを作る
5. 都市を制覇して次の都市を解放する
6. 強力な企業連合本部へ挑む

## 2. 買収戦のルール

### 2.0 開始前ブリーフィングと時間制御

交渉対象を選ぶ前から、市場カードへ`今回の動員力`を表示します。競合の実際の防衛予算を`防衛力100`へ換算し、`手元資金＋人脈＋外部協力＋SYNERGY／LIMIT BREAK＝動員力`という足し算で比べます。各項目は実際のギル計算から同じ比率で換算し、丸め後も内訳の合計と動員力が一致します。`◎余力あり / ＝接戦 / △要工夫 / ！準備不足`は勝率ではなく準備資本の目安です。AIレベル、内部判定比率、実際のギル額は前面へ重ねず、必要な場合だけ詳細を開いて確認します。小口出資不可、離反、固有ギミックなど作戦に必要な警告は常に表示します。

交渉対象を選ぶと、買収交渉の準備画面で同じ比較を大きく再表示します。自社名、競合名、都市・業界、相場、仲介手数料、敵の開幕資本25%と追加防衛枠75%、AIレベル、今回有効な事業連携（SYNERGY）と戦闘連携1枠も確認できます。「この条件で討滅戦開始」を押すまで、所有率、敵AI、行動準備ゲージ、スキル、風は進みません。開始時は「対象名 討滅戦 START!」を約3.8秒全画面表示します。現在が非静穏の風なら続けて倍率を告知し、その間は所有率・敵AI・行動準備ゲージ・リキャストを停止します。無風章または静穏中は余分な風告知を挟みません。

- 自社資金: 左の「投資レベル」で小口／堅実／強気／大口／全力を巡回し、右の「投資実行」で1回投入
- 資金源・全スキルのボトムシートを開いている間: `戦術選択中 ×0.1`。商流回復も通常の10%速度。どのコマンドも1回実行するとシートを閉じ、通常速度へ復帰
- ブリーフィング、LBチャージ、開始・風の告知、決着確認、リザルト、ヘルプ、ログ: 完全停止。SYNERGYとスキル効果は盤面上のフライングテキストで通知し、100%直前の決着演出だけ`DECISIVE SLOW ×0.16`

### 2.1 戦闘中の商流回復

買収戦中は、店舗収益や売掛金の回収を表す「商流回復」により、可処分資金が少しずつ戻ります。一気に100%へ戻る効果ではありません。

- 通常時: 対象相場の約0.3%／秒
- 資金源・全スキルのボトムシート表示中: 通常速度の10%
- 1戦の回復上限: 対象相場の15%
- 回復分は戦闘内でだけ使える回転資金で、撤退を繰り返して所持金を稼ぐことはできない

双方が資金を使い切った場合でも、数秒待てば最小投入分を再確保できます。ただし通常戦で自社所有率75%以上、自社向き圧力、競合が最低投入額未満までそろった場合だけ、所有率ゲージは毎秒8ポイント以上で決着へ進みます。競合が再投入可能まで回復するか圧力が反転すれば、この下限は即座に解除されます。

### 2.2 勝敗

- 自社所有率100%で勝利
- 自社所有率0%で敗北
- 撤退ボタンを押すと敗北扱い
- 競合が次の最低投入額を払えない間は、敵AIの再投入を待つだけの時間を作らない
- 通常戦で自社所有率75%以上かつ自社向き圧力なら、競合の流動性切れを確認してゲージの押し切りを見届ける
- 2戦目は最初の人脈投入を決着手として見せる。味方資本が押している間だけ重複入力を止め、競合の反撃と所有率ゲージは通常速度のまま動かす
- LB I解放前だけは、この押し切り中の重複コマンドを止める。演出やゲージを早回しせず、最後に積んだ自社／人脈のコインを決着手として見せる
- LB I解放後は決着前の操作を残し、貯めたLBを最後の一手として発動できる
- `LIMIT BREAK`で100%へ届いた場合はFINAL PUSHを経ず決着の一撃演出へ入る
- 100%／0%へ到達する直前は0.76秒の`DECISIVE BLOW`を挟み、最後の一撃だけスローに見せる。勝敗直後はWIN/LOSEテロップ後も最終盤面で停止し、画面下の`分析へ →`を押してからタタルの分析へ進む

通常序盤の積載・開始・決着演出は中盤以降と同じ標準速度です。短くするのは演出ではなく、競合が反撃資金を失った後の無操作待ちだけです。決着判定ではクランプ前の生所有率を保存します。

### 2.3 所有率ゲージ

戦闘中は、所有率の前線、両陣営キャラクター、金貨山、実効資本、未投入資金／追加防衛枠、双方の行動タイマーを1枚の「統合商戦フィールド」へ重ねて表示します。金貨山へ描くのは実際に投入した資金だけで、手元の未投入資金は数値表示に分離します。少額時は空の受け皿や数枚から始まり、絶対額に応じて束・壁・大山へ増え、10億ギル以上で最大の山とコイン雨になります。背景の青赤境界は勝敗判定と同じ正規化所有率です。双方が同時に100%を超え得る累計投入率は一本のゲージへ混ぜず、それぞれの金貨山の近くへ別々に表示します。

フィールド直下の細い操作帯には、ゲージを内包したLIMIT BREAK、公式ファンキットの商業アイコンで示す装備中の戦闘SYNERGY 1枠、主要スキル、資金源／全スキルを開くボタンをまとめています。未解放のLBと未装備のSYNERGYは表示しません。長いカンパニー名・交渉対象名は電光掲示板のように枠内をゆっくり往復し、戦局ログは直近1件だけ常時確認でき、全履歴はボトムシートで開きます。

内部ゲージ`G`は`-100`から`+100`です。

- `-100`: プレイヤー勝利
- `0`: 拮抗
- `+100`: 競合勝利

画面上の自社所有率は次の式です。

```text
自社所有率 = (100 - G) / 2
```

基本速度は`src/utils/formatter.ts`の`calculateGaugeVelocity()`で計算します。

```text
差額 = 自社有効投資額 - 敵有効投資額
速度 = 線形項 + 対数項
```

自社と敵がこれまで積んだ累計額の差が、所有率を連続的に動かします。ボタンを押した瞬間の小さな衝撃に加え、その後も資金差に応じてゲージが動き続けます。

### 2.4 自社資金

買収戦開始時の可処分資金は、ゲーム全体の所持金から仲介手数料を除いた額です。画面左側に残額と残り％を表示します。

| 投資段階 | 対象相場に対する投入額 |
| --- | ---: |
| 小口 | 2% |
| 堅実 | 5% |
| 強気 | 10% |
| 大口 | 20% |
| 全力 | 35% |

選択中の投資額を払えなくなった場合は、購入可能な最大段階へ自動的に下がります。払えない段階のボタンは無効になります。

### 2.5 敵の防衛資金

敵の総予算は買収開始時に固定され、無限には増えません。

```text
敵総予算 =
  現在相場
  × 物件価格帯係数
  × 企業連合本部補正
  × 業界・地域による防衛割引
  × 敵バランス補正
```

敵バランス補正はチュートリアル`×1.08`、グリダニア`×1.30`、リムサ`×1.42`、ウルダハ以降の通常戦`×1.55`、ゴールドソーサー`×1.72`、企業連合本部`×1.75`です。

- 開始時に総予算の25%を先に積む
- 残り75%が追加防衛資金
- 敵AIは所有率、風、風の残り時間、資金差、プレイヤーの直前行動を見て、投入・温存・風待ち・緊急防衛を判断
- 残予算が最低投入額を下回ると、敵AIは回復まで再投入を待つ
- すでに積んだ敵資金は、残予算が尽きても消えない

敵の追加防衛余力は段階表示へ絞り、正確な内部残額は常時表示しません。

### 2.6 風とBURST

風は市場だけの飾りではなく、買収戦の計算へ実際に入ります。ただし初心者へ最初から全種類を要求しません。

- グリダニア3戦とリムサ・ロミンサ最初の1戦: 風なし。自社投入、人脈、所有率、LB Iを順に学ぶ
- リムサで最初の事業を取得後: 味方追い風だけ解放
- リムサ制覇後: 競合追い風を追加
- ウルダハ制覇後: 自社向かい風と乱旋風を追加し、全種類を解放

解放後も風は常時吹きません。商戦は必ず静穏で始まり、最初の10秒は発生しません。その後は10秒ごとに25%で市場気配を判定し、3秒の予兆後に12～15秒だけ発生、終了後は最低18秒のクールダウンへ入ります。同じ風は原則連続しません。風の発動告知中は操作と風の残り時間を停止します。

| 風 | 実効果 | バトル演出 |
| --- | --- | --- |
| 自社追い風 | 自社有効投資額×1.35 | 青い全画面告知。味方SYNERGYも有効なら青＋金の`BURST TIME` |
| 自社向かい風 | 自社有効投資額×0.72 | 赤い防衛圧・盤面警告 |
| 競合追い風 | 敵有効投資額×1.35 | 赤い全画面警告と強い流線 |
| 乱旋風 | 双方×1.12、ゲージ速度×1.45 | 黄色い高速乱旋風 |
| 静穏 | 補正なし | 青い静穏表示 |

非静穏の風が始まるたび、画面中央へ効果倍率を告知し、所有率ゲージ上の継続表示、光条エフェクト、戦局ログも更新します。風がない間は表示枠そのものを隠します。資金塔は投入済み資本そのものを主役にし、細かな倍率内訳は戦局ログへ退避します。資金源の選択中は、風・敵行動・リキャスト・所有率がすべて0.1倍で進みます。戦闘連携や外部協力支援の実行時は`SYNERGY発動！`、味方追い風と重なれば`BURST TIME`を表示します。

### 2.7 支援資金

#### 個別の支援元（保有事業・契約）

- 対象事業・契約の相場45%を支援額として追加
- 要求ごとに独立危険度+18
- 同じ交渉中でも繰り返し要求可能
- 独立した場合、その支援元が過去に積んだ支援額も失う

#### 事業グループ

- 条件を満たした複数社へ一括要求
- 各社の相場34%を基礎に、グループ連携×1.28
- 各社の独立危険度+14

#### 外部協力・公的後援

- 同時に有効にできる協力先は1つ
- ガーロンド・アイアンワークスは企業協力。不可侵契約があり、協定企業の所有物件へ挑むと解除
- 双蛇党・黒渦団・不滅隊は公的後援。買収・所有・傘下化せず、通常物件への挑戦で自動解除されない
- 一交渉につき1回、対象相場の32%相当を支援
- GC後援は許認可・調達・輸送を含む「支援価値」として扱い、所有物件数・収益・SYNERGY・独立危険度・LB参加枠には含めない

#### LIMIT BREAK

自社と支援元による一斉出資です。回数制限はなく、同じ交渉でも攻防でゲージを再蓄積すれば2回、3回と発動できます。ALLIANCEは参加枠にも投入額にも含みません。

| 自社＋支援元の参加枠 | 段階 | 倍率 |
| ---: | --- | ---: |
| 合計1～3枠 | 未解放 | 使用不可 |
| 合計4～7枠 | LIMIT BREAK I | ×1.44 |
| 合計8～15枠 | LIMIT BREAK II | ×1.80 |
| 合計16枠以上 | LIMIT BREAK III | ×2.22 |

```text
LB基準額 = 対象相場の28%（自社枠）+ 独立しなかった全支援元の各相場28%
LB最終投入額 = LB基準額 × 段階倍率
```

- 攻防の資金衝突によるゲージ蓄積は従来比×1.20
- 発動時の一斉動員資金は従来比×1.20（上表の倍率へ反映済み）
- 直接所有率上昇の安全上限はLB I / II / IIIで10 / 20 / 30ポイント
- 発動すると、1本だけ使った場合も蓄積済みの全ゲージを必ず0へ戻す
- 発動後も攻防の資金衝突で再蓄積し、同じ戦闘中に再発動できる
- 未使用ゲージは次戦へ持ち越し、最大時はAETHER OVERFLOW演出を表示
- 各社の独立危険度+12
- 企業ごとに独立判定し、離反企業は今回のLBへ参加しない
- 離反すると、その支援元が過去に積んだ支援額も失う
- 約1.85秒の溜め中は通常進行を停止
- 適用後の生所有率が100%以上なら直接勝利
- 100%未満なら敵へ緊急防衛出資を強制し、残予算を使い切っても積載済み資本は盤面へ残す
- それでも未決着なら戦闘を続行

強力ですが、どの敵も必ず一撃で倒す即死技ではありません。

### 2.8 決着方法とOVERKILL

決着方法は`FinishMethod`として戦闘結果へ保存されます。

- `LIMIT BREAK I / II / III`
- `FINAL PUSH`
- `CAPITAL PRESSURE`（旧仕様との互換値。現行戦闘では新規発生しない）
- `NORMAL BUYOUT`

```text
生所有率 = (100 - 生ゲージ値) / 2
OVERKILL = max(0, 生所有率 - 100)
```

OVERKILLは勝ち方の派手さを表し、資金効率の優劣ではありません。0～4.9%は「精密交渉」、5～19.9%は「決定的優勢」、20～49.9%は「圧倒的買収」、50%以上は「過剰制圧」です。

### 2.9 独立危険度

独立確率は`src/utils/formatter.ts`の`calculateRebellionProbability()`で計算します。

```text
P = 1 / (1 + exp(-0.1 × (危険度 - 60)))
```

危険度10以下では独立確率を0に固定しています。ネマワシやポートフォリオの管理で危険度を下げられます。

買収戦中に独立した物件は、戦闘結果確定時に独立物件へ戻り、その物件の現在評価額が強制清算金として自社へ戻ります。

### 2.10 費用と報酬

- 仲介手数料: 対象相場の3%。勝敗・撤退に関係なく支出
- 自社直接出資の確定費用:
  - 勝利時: 投入額の35%
  - 敗北・撤退時: 投入額の75%
- 勝利時運転資金: 対象相場の5%
- 取得物件の`annualRevenue`: 実装上は「毎秒収益」
- 支援資金は直接出資の確定費用へ含めない
- 幻・商戦は参加費・攻略報酬・確定費用がすべて0で、通常の商会資金、所有権、人脈、独立危険度、持越しLB、進行へ結果を反映しない

### 2.11 業界・地域・交易網ボーナス

#### 業界影響力

| 条件 | 表示 | 効果 |
| --- | --- | --- |
| 2件保有かつ40%未満 | 顔が利く | 表示のみ |
| 3件以上または40%以上 | 影響力 | 自社押込+5% |
| 過半数 | 業界掌握 | 自社押込+10%、敵予算-10% |

#### 地域影響力

| 条件 | 表示 | 効果 |
| --- | --- | --- |
| 1件以上 | 足場を築いた | 自社押込+3% |
| 半数以上 | 地域優勢 | 自社押込+8%、敵予算-5% |
| 都市制覇 | 地域制覇 | 自社押込+12%、敵予算-8% |

都市制覇1件ごとに交易網補正+2%。最大+16%です。

### 2.12 かけひき

| スキル | 実装上の効果 |
| --- | --- |
| 疾風怒濤の計 | 10秒間、行動準備ゲージ進行を約1.8倍（再使用18秒） |
| 守りのサンバ | 買収戦に参加中の全支援元の独立危険度を半減 |
| 連環計 | 9秒間、敵追加防衛を70%で中断し、既投入額を相場12%まで崩す |
| 消沈 | 9秒間、敵の追加防衛間隔を1.6倍へ延長 |
| 意気衝天 | 一交渉1回、対象相場の30%を無料支援資金へ追加 |
| リビングデッド | 総資産100万ギルで解放。一交渉1回、10秒の待機中に所有率0%へ到達すると表示上1%で耐える。攻防の内部値は進み続け、次の10秒で正規化所有率30%以上へ戻せなければ敗北 |
| バトルリタニー | 7秒間、所有率の押し込み速度×1.5 |

スキル名はFFXIVの公式アクションをモチーフにし、効果は交易戦向けの本作独自アレンジです。名称、解放条件、説明文は`src/data/initialData.ts`にあります。物件・業界・総資産・SYNERGYの修得条件は装備画面と戦闘の両方へ適用されます。効果の実処理は`BattleModal.tsx`の`useSkill()`です。旧セーブ互換のためリビングデッドは旧`skill_sns_blitz` IDを維持します。

戦闘中は`特殊アクション`欄から装備スキルとLBを1タップで実行できます。各ボタンは名称と主要効果だけを示し、詳しい説明はスキル画面で確認できます。実行後は自社資金パネルと通常速度へ戻ります。味方と敵のアクション待ちは、同じ幅の秒表示＋進行バーで比較できます。

### 2.13 セーブについて

セーブは`localStorage`へスキーマバージョン3として自動保存されます。

- 保存される: カンパニー名、所持金、物件の所有・独立危険度、装備スキル、外部協力／公的後援、解放説明の既読ID、保存時刻
- 保存されない: 戦闘途中、風、市場の一時変動、行動準備ゲージ、戦闘内クールダウン

有効なセーブがあれば起動演出を飛ばして自動ロードします。復帰時は現在の毎秒収益を基準に最大30分分のオフライン収益を加算します。ヘッダーの回転矢印から確認後にセーブを削除できます。

## 3. ロマサガ3トレードとの違い・難易度設計・Codex所感

### 3.1 原作から受け継いでいる核

このゲームは『ロマンシング サ・ガ3』のトレードを完全再現したものではありません。原作のキャラクター展開やイベント進行ではなく、次のゲームループをFF14風の題材へ移植した作品です。

- 物件を買収して傘下を増やし、より大きな相手へ挑む
- 自社資金だけでなく、保有事業・契約の支援元や事業グループから資金を集める
- 資金量の差によって、リアルタイムに買収の優勢・劣勢が動く
- 強い資金要求には物件独立の危険が伴う
- 守りのサンバや疾風怒濤の計などの「スキル」で資金戦を有利にする
- 特定の物件の組み合わせを集め、グループ資金を主力に育てる

原作でも、物件から集めた資金とグループボーナス、かけひき技、独立危険度の管理が買収戦の中心です。本作も「大金を持つこと」だけでなく、「どこから、いつ、どれだけ調達するか」を中心にしています。

### 3.2 実際の実装が原作と異なるところ

| 項目 | ロマサガ3トレード | 現在の本作 |
| --- | --- | --- |
| 進行 | 3段階のトレードイベントと目標企業・組織の買収 | グリダニアから10都市を順番に制覇するキャンペーン |
| 世界・物件 | ロマサガ3の町、会社、産業グループ | FF14主要都市、ショップ、組織、産業を題材に再構成 |
| 買収の見せ方 | 一本の買収ゲージと資金要求を一画面で処理 | 所有率ゲージ、両陣営の資金残量、積み上げコイン、風、ドットキャラを同一戦闘画面に表示 |
| 自社資金 | 総資産から支出するかけひきも含む | 戦闘開始時に使用可能資金を確定し、相場比2～35%の段階投入 |
| 敵資金 | 相手物件ごとの内部パラメータとAI行動 | 相場・価格帯・企業連合本部・影響力から予算を算出し、25%を初期投入、残り75%を判断型AIが追加・温存 |
| 資金切れ | 資金競争の結果としてゲージで決着 | 競合が最低投入額未満かつ自社優勢75%以上なら、最後に積んだ資本を決着手としてゲージを押し切る |
| グループ技 | 所有物件の組み合わせから発生し、主要な資金源になる | 事業グループ、個別支援元、協力、全支援元投入`LIMIT BREAK`に分割 |
| 独立 | 資金要求やグループ技の重要なリスク | 確率式を画面上の危険度として可視化。独立すると、その支援元から積んだ過去支援額も崩落 |
| かけひき | 習得条件や対象相性を持つ多数の技 | 8スキルに整理し、クールダウン制、敵妨害、即時資金、速度強化、時代の風として実装 |
| 時間変化 | コマンド待ち時間とゲージ速度・加速度 | コマンドゲージ、敵AI間隔、微動・急変、5種類の風による倍率変化 |
| 成長 | 物件価値やグループ形成を利用してイベント目標を達成 | 所有物件の収益、業界影響力、地域影響力、都市制覇による交易網補正を累積 |
| セーブ | RPG本編のセーブデータ内で進行 | `localStorage`へ攻略状態を自動保存し、最大30分のオフライン収益を回収 |

資金切れ後も即時勝利にはせず、最後に積んだ自社・人脈・LBのコインとゲージ移動を見届けて決着します。競合が再投入できないのに同じボタンを重ねる待ち時間だけを省き、原作の「積んだ資本が相手を押し切る」読み味を優先しています。

本作ではランダムな環境効果を「市場の風」、プレイヤーが発動するスキルを「時代の風」として分離しています。市場の風は商戦ごとに静穏から始まり、最低10秒の猶予後に低頻度で予兆・発生します。「時代の風」は敵資金を消さず、運用資金と引き換えに12秒間だけ自社向きの独立した時流を加える逆転技です。

### 3.3 現在の難易度を決めている基準

難易度は反射神経より、次の3つを理解して遊ぶ基準に設定しています。

1. **資金効率**
   自社資金を連打すれば短期的には強い一方、勝利後も資金を残さなければ次の物件へ進めません。安い物件から傘下を作り、支援資金を増やすほど有利になります。
2. **投入タイミング**
   敵の残予算、所有率の移動、風、コマンド回復を見て投入します。敵が資金を追加した直後、追い風中、または反撃資金が尽きる直前の人脈・LBが主な判断点です。
3. **傘下リスク管理**
   個別要求、グループ要求、`LIMIT BREAK`は手元資金を減らさず大きく押せますが、独立危険度が上がります。守りのサンバを挟むか、危険を承知で一斉投入するかが中盤以降の賭けになります。

敵予算は価格帯別基礎値に、チュートリアル1.08、グリダニア1.30、リムサ1.42、ウルダハ1.55、ゴールドソーサー1.72、企業連合本部1.75の段階補正を掛けます。敵は25%を初期投入し、残り75%は風・所有率・資金差・直前行動・都市段階に応じて積むか温存します。したがって、単に相場と同額の現金を持っているだけでは安定勝利になりません。

想定している標準的な遊び方は次の通りです。

- 序盤: 初戦は自社資金を数回積み、2戦目は自社の後に人脈、4戦目は自社と人脈の後にLB Iで決着する
- 中盤: 同業・同地域の物件を揃え、個別支援と事業グループを主力にする
- 終盤: 敵予算を影響力で削り、守りのサンバ、妨害スキル、風、`LIMIT BREAK`を組み合わせて大型物件を崩す

通常キャンペーンの基準相場は、グリダニアの2K～15Kからトライヨラの6.5Mまで段階的に上昇します。公式拡張順へ合わせたうえで、ラザハンは5.5Mへ調整し、中盤後半の価格逆転を防いでいます。ゴールドソーサーはウルダハ内の例外的な強敵で、その直後のイシュガルドは一度立て直せる価格帯です。東アルデナード商会と一部の知識・技術交易連盟は「任意の連合戦」として都市解放条件から外れますが、最終都市ソリューション・ナインの参加組織2件は都市制覇対象です。

このため、最初から高額物件へ正面攻撃する遊び方は難しく、安い物件から買収網を組み立てる遊び方を標準としています。逆に、資金源と影響力を十分に育てれば、後半は「蓄えた経済圏を一斉に動かす」強さを実感できる設計です。

### 3.4 Codexとしての所感

現在の実装は、ロマサガ3トレードの**完全再現ではなく、核を借りたリアルタイム資金バトル**です。資金源を増やす喜び、グループ技で桁の違う金を動かす快感、独立を恐れながら資金を求める緊張感は、かなり原作の方向へ近づいています。とくに、積み上がるコイン、背景とゲージの押し合い、最後に使った自社・人脈・LBが決着手として残る盤面は「何に勝ったのか」を本作独自の方法で伝えています。

一方で、原作ほど完成していないのは**長期の経済設計と、選択肢ごとの個性**です。現在は個別支援元、事業グループ、`LIMIT BREAK`の多くが「投入額と独立リスクの違い」に集約されており、十分な支援元を得た後は強い資金源を順番に押すのが正解になりやすいです。原作にあった、物件の組み合わせを探す面白さ、技の効きやすい相手を見抜く面白さ、限られた経済圏で攻略手順を考える余地は、まだ拡張できます。

敵AIは都市段階に応じて賢くなり、優勢時の無駄な追随を止め、小口の囮を見送り、プレイヤー追い風の終了を待ち、大口やLBだけへ素早く反応します。特にゴールドソーサーは序盤の最初の強敵です。自滅待ちは完全に禁止していませんが、風と投入額を読んで敵の予備資金を吐かせる準備が必要になりました。

完成度を一段上げるなら、敵の数値を単純に増やすよりも、次の方向が合っています。

- 物件ごとに「小口へ強い」「大口投入後に反撃」「特定業界の資金を崩す」などの防衛個性を付ける
- グループごとに調達速度、上限、独立しやすさ、風との相性を変える
- 勝利時の残金、独立ゼロ、短時間決着などを評価し、上手い勝ち方を可視化する
- 都市ごとに推奨資金帯を示し、易しさではなく準備不足の理由を伝える
- 攻略状態を保存し、10都市制覇を一続きの経営判断として成立させる

Codexの評価では、現版は「ギルを積んで押し合う瞬間」はゲームになっています。次の課題は、勝敗の前後をつなぐ経営判断を厚くし、**同じ勝利でも、どの資金網を作り、どのリスクを取ったかによって手触りが変わるゲーム**へ育てることです。

### 4.5 買収開始から精算まで

1. `MarketView.handleBuyoutClick()`がカードに表示した基準価格を`Property.marketPrice`へ入れる
2. `App.handleStartBuyout()`が都市解放を確認し、`activeBattleProperty`へ設定
3. `BattleModal`が仲介手数料、敵予算、戦闘内残高を初期化
4. 戦闘中は`BattleModal`内だけで投資・AI・ゲージを管理
5. `confirmResult()`が精算値を`App.handleBattleEnd()`へ返す
6. `App`が所持金、所有権、独立、都市解放を確定

リザルトが出た時点ではまだ全体状態へ反映しません。「買収結果を確定する」を押した時に`onBattleEnd()`が走ります。

### 4.6 市場価格

通常市場は`Property.marketPrice`を基準価格として固定します。敵選択中に見えない価格更新で戦力等級が変わることはありません。対象カードでは株価風の騰落率や内部AI値を並べず、防衛力100に対する動員力の足し算、勝利後に増える人脈・連携、開始手数料を優先します。

### 4.8 画像・音声の方針

- キャラクター、ジョブアイコン、背景、木人訓練のサボテンダー等ミニオンアイコンは公式FF14ファンキット素材だけを使用
- 資金チップはユーザー提供のギル硬貨画像を透過・縮小・色調整したPNGを使用
- 新しい画像を追加するときは出典と利用条件を確認
- 第三者サイトから拾った画像やゲーム画面の無断切り抜きを追加しない
- 討滅戦開始、機能解放、LIMIT BREAK、勝敗は公式ファンキットの着信音SEを優先。配布MP3も合成SEも同じWeb Audio出力へ読み込み、iPhoneでも資金音・行動音と重ねて再生します。読み込み／自動再生失敗時は合成音へフォールバックします
- 公式配布外のFF楽曲や音源は追加しない。決着の打撃音や資金投入音はプロジェクト独自の合成音

### 4.9 現在の既知仕様・注意点

- 攻略状態は`localStorage`保存。別端末・別ブラウザには同期しない
- `annualRevenue`という名前だが、ゲーム上は毎秒加算し、実収益は一括定数で2倍
- 戦闘開始後にApp側で増えた毎秒収益は、戦闘内`cash`へ同期しない
- 風の段階は都市制覇数と所有数から導出し、セーブ項目を増やさない。商戦内の風は毎回CALMから始まり、最低10秒の静穏、10秒ごとの25%判定、3秒予兆、12～15秒継続、最低18秒クールダウンで進む
- 戦闘内支援額は「借入金」ではなく、精算コストなしの支援戦力として扱う
- `UPDATE`には未実装案と実装済み案が混在
- `public/game/`は生成物だが、Sitesから配信するためGit追跡対象

### 4.10 改修時のチェックリスト

1. ルール変更ならゲーム内ヘルプとREADMEも更新する
2. 勝利条件を変える場合、通常ゲージ勝利、人脈決着、LIMIT BREAK決着を確認する
3. 資金コマンドを変える場合、表示額、実投入額、独立崩落額、リザルト分析を揃える
4. 市場表示の風と商戦ローカルの風を混同せず、商戦開始時に必ずCALMへ初期化されることを確認する
5. 360px前後のスマホ幅で、コマンドと下端余白を確認する
6. `npm run lint`
7. `pnpm run check:balance`
8. `pnpm run build`
9. `public/game/`のハッシュ付きJS/CSSと`index.html`を一緒にコミットする
10. 非公開デプロイ先のURL、アクセス範囲、アカウント情報を公開リポジトリへ記載しない
11. 公開前にREADMEと引き継ぎ文書を検索し、非公開URLが混入していないことを確認する

## 5. 開発・起動

### 必要環境

- Node.js 22.13以上
- pnpm

### インストール

```bash
pnpm install
```

### ローカル開発

Sitesラッパーを含む開発サーバー:

```bash
pnpm run dev
```

ゲーム単体:

```bash
pnpm run dev:game
```

Windowsでは`start-game.bat`からゲーム単体の開発サーバーを起動できます。

### 検査

```bash
pnpm run lint
pnpm run check:balance
```

`lint`の実体は`tsc --noEmit`による型検査です。`check:balance`は都市別価格・収益、都市制覇対象、敵AIの代表判断、スキル解放、LIMIT BREAK実額を決定論的に検査します。

### 本番ビルド

```bash
pnpm run build
```

ビルドは二段階です。

1. Viteゲームを`public/game/`へ生成
2. vinext/Sitesラッパーを`dist/`へ生成

`app/page.tsx`は`/game/index.html`をiframeで表示します。`app/layout.tsx`はOGPを含むSites側メタデータを担当します。
