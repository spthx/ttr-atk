# タタルの大繁盛店

スマホで遊べる、買収・市場観察・資金管理をテーマにしたブラウザ金融ゲームです。プレイヤーはタタル本人ではなく、タタル商会の「交易実務担当」として市場調査・買収・資金管理を行います。タタルは商会長として報告を受け、判断材料と助言を示します。キャラクターストーリーやフィールド探索は扱いません。

## 世界と勝利目標

- 各物件はいずれかの都市商圏に属します。
- その都市の全物件を取得すると都市制覇です。
- PDFで主要経済圏として挙げられた全10都市の制覇が最終目標です。
- 市場画面の都市チップから、取得数・残り物件・制覇状況を確認できます。

## 現在のゲーム内容

### 基本ループ

1. 市場から物件を選び、仲介手数料を払って買収工作を始めます。
2. 自社出資、傘下・同盟からの支援、かけひきコマンドで買収ゲージを有利にします。
3. ゲージを勝利側まで押し切ると物件を取得し、保有物件から継続収益を得ます。
4. 収益・グループシナジーを元手に、より大きな物件や企業連合へ挑みます。

### 画面内ヘルプ

- 市場上部の「はじめての方へ」は閉じた状態から必要なときだけ開けます。
- 「？」にマウスを重ねるか、タップ／キーボードで選択すると用語説明を表示します。
- 買収交渉中は右上の「操作」から、勝利条件・直接出資・支援・相場の要点を確認できます。
- 絞り込みで物件が0件になった場合は、表示されたボタンで検索条件を一括解除できます。


### 買収工作

- **敵防衛予算**: 敵の予算は買収工作の開始時に固定されます。敵の反撃は残予算の範囲だけであり、無限に資金が湧くことはありません。
- **自社出資**: 出資レベルを選び、追加出資に使える残高から資金を投入してゲージを押します。勝利時は直接出資の35%、敗北時は75%が最終的な支出になります。
- **買収時の運転資金**: 勝利すると、対象物件の相場5%にあたる現金を即時に獲得します。さらに取得物件の継続収益が以後毎秒入ります。
- **傘下・同盟支援**: 傘下会社への要求はその交渉中に各社一度だけです。強力ですが、傘下の独立危険度が上がります。同盟支援も一交渉に一度だけです。
- **市場損益**: 交渉中も保有事業の収益と小さな市場変動により、可処分資金が毎秒わずかに上下します。資金不足でも、状況を見て待てば小口出資の余地が生まれます。
- **追証警戒**: 可処分資金が安全ラインを割り、かつ敵に押されていると警告を表示します。即時敗北にはしませんが、支援・待機・撤退を判断する危険な局面です。
- **相場と風向き**: 強気・警戒・出来高増などの市場状態と、追い風・向かい風が出資効率やゲージ進行に影響します。
- **業界影響力（試験導入）**: 同業界の物件を3件以上、または40%以上保有すると、その業界への自社出資が5%強くなります。過半数を取ると「業界掌握」となり、自社出資+10%・敵防衛予算-10%です。買収画面で対象業界の進捗を確認できます。

### かけひきコマンド

買収交渉画面の「かけひき」タブで使用します。各ボタンはマウスオーバーで詳細を確認できます。

| コマンド | 効果 | 使いどころ |
| --- | --- | --- |
| 早馬 | 8秒間、他コマンドの再使用時間を半減 | 連続して技を使いたい直前 |
| ネマワシ | 傘下会社の独立危険度を下げる | 傘下支援を使った後 |
| 資本即時投入 | 対象相場の30%分を即時投入 | 敵の反撃前、追い風・強気相場 |
| SNS工作 | 敵の有効防衛を一時的に崩す。7秒後に敵の残予算から反論が来る | 敵の残予算が少ない終盤 |

## 起動

Windowsでは [start-game.bat](./start-game.bat) をダブルクリックするだけで起動します。ブラウザが自動で開きます。

コマンドで起動する場合は、Node.js 22以降で実行します。

```bash
npm ci
npm run dev
```

## GitHub Pagesへの公開

1. このフォルダをGitHubリポジトリにpushします。公開用ブランチは `main` を想定しています。
2. GitHubの **Settings → Pages → Build and deployment** で、Sourceを **GitHub Actions** にします。
3. `main` へpushすると `.github/workflows/deploy-pages.yml` がビルド・公開します。

Viteは相対パス（`base: './'`）で設定済みのため、プロジェクトページでもアセットパスが崩れません。

## 本番ビルド

```bash
npm run build
```

生成物は `dist/` に出力されます。
