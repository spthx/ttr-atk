# 大繁盛エディタ 仕様書

## 1. 目的

「大繁盛エディタ」は、現行ゲームの仕組みだけを使い、プログラムを書かずに敵、味方、物件、スキル、台詞、難易度、演出順を編集する制作ツールである。RPGツクールのような汎用エンジンではなく、買収バトル専用の安全なコンテンツ編集UIとする。

最初はWeb上のローカルツールとして実装し、JSONを書き出す。将来Unity EditorWindowへ移す場合も同じスキーマを使う。

## 2. 編集対象

### 2.1 世界と進行

- 都市、時代、地域順
- 物件・契約
- 市場価格、収益、競合、ボス、業種
- 解放条件、前提ID、クリア後の遷移
- 零式シリーズ、1～4層、絶、酷

### 2.2 プレイヤー要素

- アビリティ名、説明、効果、継続時間、クールダウン
- 開幕オート、窮地オートへの設定可否
- 手動シナジーと自動置換順
- LB段階、必要量、押し込み上限、資本上限
- 人脈、味方出資、離反、利益配分（利益独占0%／五分の祝儀50%／大盤振る舞い100%）

### 2.3 敵要素

- 表示キャラクター1～3体
- 通常AIの反応間隔、投入倍率
- 開幕・窮地・手動アクション
- ケアル、切り崩し、ドリル、相場誘導、速攻、LB3
- ナイトのかばう、強化かばう、インビンシブル、パッセ
- 宣告、台詞、カウントダウン、段階遷移

## 3. 画面構成

### 3.1 プロジェクト

- 新規作成
- JSON読込
- JSON書出
- 検証
- 直前の自動バックアップ
- スキーマ移行プレビュー

### 3.2 コンテンツ一覧

左側にカテゴリ、中央にID一覧、右側に編集フォームを置く。表示名の変更でIDを変えない。削除時は参照箇所を一覧表示し、参照が残る間は削除できない。

### 3.3 バトルプレビュー

選んだ敵、資金、スキル構成、乱数シード、画面サイズを指定して1戦を再生する。

プリセット:

- 402×874
- 393×786
- 874×402
- タブレット横持ち
- 1440×900

表示項目:

- 所有率と速度
- 双方の投入済み・残資金
- 行動キュー
- 一時DOM/オブジェクト数
- 進行中のタイマー
- 勝敗、時間、出資回数

## 4. アクション定義

アクションは「表示」と「効果」を分離する。

```json
{
  "id": "enemy_quote_001",
  "presentation": {
    "actorKey": "boss_a",
    "nameTextId": "action.quote.name",
    "telegraphTextId": "action.quote.telegraph",
    "quoteTextId": "action.quote.line",
    "telegraphMs": 1200,
    "castMs": 800,
    "impactMs": 0,
    "afterglowMs": 900,
    "leavingMs": 400
  },
  "effect": {
    "type": "presentation_only",
    "params": {}
  },
  "interruptibility": "unstoppable"
}
```

許可する効果型はホワイトリストにする。

- `presentation_only`
- `recover_reserve`
- `push_ownership`
- `add_capital_support`
- `modify_investment_multiplier`
- `modify_action_speed`
- `mark_next_hit`
- `delay_action`
- `cover`
- `invincible_then_cover`
- `set_ownership_ceiling`
- `scripted_ownership_loss`

任意JavaScript、任意C#、式文字列は入力させない。

## 5. シナジーの置換

手動シナジーは一覧へ増え続けるのではなく、進行に応じて同じ選択枠の候補が自動で上位へ置き換わる。

現行の進行:

```text
既存地域シナジー
→ クリスタルブレイブ（失敗試作として短期間）
→ 希望の灯
→ グランドカンパニー・エオルゼア
```

希望の灯とグランドカンパニー・エオルゼアは、ウルダハ系シナジーより明確に強い。エディタは置換元、解放条件、優先度、倍率、持続、即時押し込みを同時に表示する。

## 6. オートアビリティ

ロードアウト画面に次の専用枠を持つ。

- 開幕オート
- 窮地オート
- 通常選択枠

開幕または窮地に装備したアビリティは通常枠から外す。同じIDの重複装備を禁止する。オート発動も通常と同じ演出キューへ入り、演出中に次の同格表示を重ねない。

## 7. バリデーション

書き出し前に次をエラーにする。

- ID重複、空ID、参照切れ、循環する前提条件
- 負の金額、0以下の継続時間、所有率範囲外
- `presentation_only`に数値効果が設定されている
- `unstoppable`なのにスタン必須の説明がある
- ボスの無敵に後続パッセまたは回復後の防衛がない
- 零式が3シリーズ×4層になっていない
- 上位シナジーが置換元より弱い
- 一戦の推定出資回数が30以上、推定時間が120秒以上
- コイン列22、層36、一時コイン16の上限超過

警告:

- 初心者対象に複数ギミックがある
- 開幕行動が操作説明より先に発火する
- フライングテキストが短すぎる
- 同一時刻に複数のシネマティックが予約される

## 8. シミュレーション

編集内容ごとに固定シードの簡易AIで最低500戦を実行できるようにする。

集計:

- 勝率
- 中央値、p90の戦闘時間
- 中央値、p90の出資回数
- 赤字・黒字率
- 使用されたLB、シナジー、アビリティ
- ケアル回復量、かばう吸収量、パッセ消費量
- 無敵解除から決着までの時間
- 第二宣告の成功・失敗率

「勝てる」だけでなく、特定の一手だけに偏っていないかを表示する。

## 9. 書き出し

出力物:

```text
manifest.json
world.json
properties.json
skills.json
synergies.json
encounters.json
raids.json
text.ja.json
assets.json
```

各ファイルに`schemaVersion`と`contentVersion`を含める。出力順を安定させ、Git差分が読みやすい整形JSONにする。正式アセットはコピーせず、論理キーと相対パスだけを書き出す。

## 10. 実装段階
