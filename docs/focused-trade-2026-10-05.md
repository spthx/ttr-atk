# 商戦UI整理と積載時計（2026-10-05）

目的：コイン、所有率、次の行動を同時に読める画面へ整理する。

- 取得できない都市は「この先の交易路」に収納。開放済み都市はそのまま選べる。
- 初戦で候補が1つだけの技切替ボタンを撤去。発動ボタンへ技名と効果を集約。
- 重複する操作見出し、中央CAPITAL、一般的な説明文、枠と発光を整理。投資は金額選択＋実行の2操作を維持し、投資実行を金色の主操作とする。
- PCの盤面を拡大。縦持ちは55dvhを上限とし、横持ちは低背用に操作列を縮める。
- 少量だけ3位置に丸めていた落下を連続した加速軌道へ変更。大量の短束連射、18アンカー、完成山と皿の同期下降を共用する。
- 積載中に盤面をタップすると、その時動いている積載の残りが2倍速。連打しても4倍にはならず、次の出資では1倍へ戻る。途中経過を持ち越してタイマーを再予約し、描画時計・音源速度・行動準備量も合わせる。

他タスク参照：既存の独立金貨監査（2026-10-03）の最小8枚、4DPR、接地、背景キャッシュ条件を保持。「Plicy内トレードゲーム確認」は別作品のスマホ設計で、状況と主操作を同時表示し内訳を折り畳む方針を参考にした。新規の他タスク起動や依頼送信はしていない。

検証：型、既存visual/contact/rendering/theme、balance/readiness/progression、500戦simulation、roll-stream、app-performanceを実行。追加の仮想時計検査は100ms通常＋115ms倍速で330ms分が一度だけ完了すること、後続の速度継承・連打・キャンセル・速度リセット・少量の連続軌道を確認。

ブラウザ実操作：初戦開始、通常700ギル出資、続く700ギル出資で盤面タップ→「積み上げ×2」→投入総額1,400ギル、決着画面までを確認。390×844と844×390のiframe内で実ゲームのレスポンシブ配置を目視確認した。端末実機と音の試聴は未実施。以前の独立GPU全4,188件を今回再実行したとは扱わない。
