## Task 2 — 買収戦バランス

通常20戦、商戦 零式4層、絶の25戦闘を4戦略×80シードで比較し、風固定5条件×250シードを加え、合計9250戦を実行しました。

主結果:

- 標準代理「支援元へ一巡→10%出資→LB」は通常20戦中18戦で勝率97%超。通常編平均勝率94.8%。
- 初心者代理「全力出資連打」の通常編平均勝率は46.8%。大口出資へ敵AIが反応するため、支援運用との差が大きい。
- トライヨラ最後の価格6.5Mからソリューション・ナイン最初の300Mへ約46倍上昇する。
- 300Mの「ソリューション・ナイン装備産業群」は標準代理0%、熟練現地調達0%、準備完了代理100%。
- その300M物件を取得した後の450M「エレクトロープ電力事業体」は標準代理96.3%。最終都市内で最初だけ極端に強く、その次が急に易しくなる。
- 準備完了代理の勝率は、零式1層100%、2層100%、3層100%、4層91.3%、絶56.3%。
- 標準代理は零式1層95.0%、2層61.3%、3層以降0%。熟練現地調達も3層以降0%。高難度は開幕から大資本・LBを出せるかで二極化する。
- トラル香珈琲交易所では風を固定しても標準代理の勝率は全条件100%。平均時間だけ自社追い風7.3秒、向かい風16.0秒へ変化した。支援が雪だるま化した通常戦では、風が勝敗より時間だけを動かす。

注意: 代理はBattleModalの資金投入ショック、継続ゲージ、敵AI、回復、風、支援、SYNERGY、協力支援、LB緊急防衛、都市ボスかばう、精算を再現する一方、連環計・リビングデッド・時代の風など一部手動アビリティを含みません。絶対勝率より同条件の戦略差・章間差を重視します。

## Task 3 — 経済進行・詰み

4方針×250回の合計1000キャンペーンを、各戦闘前に仲介手数料と市場価格80%の持込現金を確保してから、通常10都市→零式→絶まで実行しました。別に独立・清算サイクルを1000回実行しました。

| 方針 | 通常編完走 | 零式4層完走 | 絶完走 | 通常編平均 |
|---|---:|---:|---:|---:|
| 無計画・全力連打 | 0.0% | 0.0% | 0.0% | — |
| 安物優先・支援一巡 | 97.2% | 0.0% | 0.0% | 21.4分 |
| 収益効率優先・熟練運用 | 48.8% | 10.0% | 0.0% | 25.5分 |

- 1000回中、資金も毎秒収益もなくなる真のソフトロックは0件。
- 無計画・全力連打は全250回がゴールドソーサー戦で停止した。資金詰みではなく戦略壁。
- トライヨラ制覇からソリューション・ナイン制覇まで、安物優先13.0分、収益効率優先13.7分、全機能運用10.0分。最終都市だけで前半9都市に近い時間を使う。
- 通常制覇後、最初の零式へ必要な追加待機は平均3～12秒で、通常→零式間の資金橋は問題にならなかった。

### 重大: 独立・全額清算ループ

対象は市場価格450,000,000ギルの「エレクトロープ電力事業体」。

- 危険度100からの独立: 901 / 1000 = 90.1%
- 独立時清算返金: 450,000,000ギル
- 平均再買収費用: 130,146,892ギル
- 独立1回あたり平均差益: 319,853,108ギル
- 平均差益は市場価格の71.1%
- 独立した901件はすべて6回以内に再買収成功

市場価格100%を返す現在の清算式により、意図的に危険度を上げて独立させ、全額返金後に再買収する金策が成立します。今回の平均再買収費用は市場価格の28.9%なので、清算返金を20%前後へ下げると反復期待値はマイナスになります。
